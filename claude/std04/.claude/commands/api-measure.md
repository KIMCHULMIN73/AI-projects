---
description: 모델 응답을 실측해 PRD.md의 수치 표를 갱신한다
---

PRD의 수치(지연 시간·토큰·정확도)는 추정이 아니라 측정값이다. 프롬프트나 모델을 바꿨으면 다시 재고 표를 갱신한다.

1. `tools/smoke_test_api.py`로 두 모델이 응답하는지 먼저 확인한다.
2. 재는 항목:
   - 비전 1회 지연·입출력 토큰 (`/api/vision`의 실제 프롬프트로)
   - 텍스트 1회 지연·출력 토큰
   - 식재료 인식률·분류 정확도 (정답을 아는 이미지로. 라벨을 아는 합성 이미지가 가장 확실하다)
   - JSON 파싱 성공률 (텍스트 모델은 스키마 강제가 안 되므로 3회 이상)
3. `PRD.md`의 **실측 근거** 표를 새 값으로 고치고 날짜를 바꾼다.
4. 값이 크게 달라졌으면 그 수치에 기대던 사양도 함께 본다 — `max_tokens`(`UNIT_model_call`), 타임아웃과 대기 문구(`UNIT_ui_state`)가 특히 그렇다.

측정용 스크립트는 스크래치패드에 두고 `tools/`를 어지럽히지 말 것. 반복해서 쓸 가치가 생기면 그때 `tools/`로 옮긴다.
