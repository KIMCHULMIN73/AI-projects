대상: **$ARGUMENTS** (비어 있으면 DB에 있는 문항 전체)

최상급 표현은 **기준이 없으면 정답이 둘 이상이 되는** 가장 흔한 원인이다. CLAUDE.md 「퀴즈 문제 교차 검증 가이드라인」 2번이 이걸 다룬다.

**찾는 데서 끝내지 말고 개선안까지 낼 것.** 목록만 늘어놓는 것은 이 명령어의 절반만 한 것이다.

## 대상 고르기

| 입력 | 무엇을 볼까 |
|---|---|
| 비었음 | `data/questions/*.js` 400문항 전체 |
| `science` 등 분야명 | 그 파일만 |
| `SC-012` 같은 id | 그 문항만 (앞뒤 맥락까지 읽을 것) |
| 문항 텍스트를 직접 붙여넣음 | **파일에 없는 새 문항**이다. 아래 스크립트 대신 눈으로 읽고 곧장 2단계로 갈 것 |

새로 쓴 문항을 은행에 넣기 전에 거르는 것이 이 명령어의 주 용도다. 스크립트는 기존 파일용 보조 수단일 뿐이다.

## 1. 찾기

```bash
cd quiz-game && python3 - <<'PY'
import re, glob, sys
from collections import defaultdict

OBJ = re.compile(r"\{\s*\n\s*id:\s*'([^']+)',(.*?)\n  \},", re.S)
Q   = re.compile(r"\n\s*question:\s*(\"(?:[^\"\\]|\\.)*\"|'(?:[^'\\]|\\.)*')")

PATS = {
    '가장': r'가장',
    '최초/처음': r'최초|처음',
    '최대/최소': r'최대|최소',
    '최고/최저': r'최고|최저',
    '최장/최단/최다': r'최장|최단|최다',
    '유일': r'유일',
    '제일': r'제일',
}
CATNAME = {'korean-history':'한국사','science':'과학',
           'world-geography':'세계지리','arts-culture':'예술·문화'}

target = sys.argv[1] if len(sys.argv) > 1 else ''
hits, total = defaultdict(list), 0
for path in sorted(glob.glob('data/questions/*.js')):
    stem = path.split('/')[-1][:-3]
    if target and target != stem:
        continue
    src = open(path, encoding='utf-8').read()
    for m in OBJ.finditer(src):
        total += 1
        qm = Q.search(m.group(2))
        if not qm:
            continue
        text = qm.group(1)[1:-1]
        tags = [n for n, p in PATS.items() if re.search(p, text)]
        if tags:
            hits[CATNAME[stem]].append((m.group(1), tags, text))

n = sum(len(v) for v in hits.values())
print(f"{total}문항 중 최상급 표현 포함: {n}문항\n")
for cat, rows in hits.items():
    print(f"── {cat} ({len(rows)}건) " + "─"*40)
    for qid, tags, text in rows:
        print(f"  {qid}  [{'/'.join(tags)}]  {text}")
    print()
PY
```

분야를 지정하려면 히어독 뒤에 파일 이름(확장자 없이)을 인자로 붙인다.

## 2. 판정

찾은 것을 그대로 늘어놓지 말고 **기준이 있는지 없는지로 갈라서** 보고할 것. 최상급이 있다는 것 자체는 결함이 아니다 — 기준이 없는 것이 결함이다.

| 판정 | 뜻 | 개선안이 필요한가 |
|---|---|---|
| ✅ 기준 있음 | 문제에 무엇을 기준으로 한 최상급인지 적혀 있다 | 필요 없음 |
| ⚠️ 기준 없음 | 최상급인데 기준이 없다. 다만 보기에 경쟁자가 없어 실무상 답은 하나다 | 있으면 좋음 |
| 🔴 정답 충돌 | 다른 기준으로 읽으면 **보기 중 다른 것이 답이 된다** | 반드시 |

**⚠️와 🔴은 보기 4개를 봐야 갈린다.** 문제 텍스트만 보고 판정하지 말 것 — 기준이 없어도 보기에 경쟁자가 없으면 답은 하나다. 반대로 기준이 있어 보여도 보기에 다른 기준의 정답이 있으면 🔴이다.

의심스러우면 검색으로 확인할 것. 특히 **수치가 걸린 최상급**(높이·넓이·깊이·인구)은 값이 낡았을 수 있다.

기준이 잘 붙은 예:

- `해발고도가 세계에서 가장 높은 산` — 산기슭 기준이면 마우나케아
- `면적 기준으로 세계에서 가장 넓은 호수` / `담수호 가운데 면적이 가장 넓은 호수` — 카스피해와 슈피리어호를 갈라 준다
- `국제적으로 인정받는 나라 중 국토 면적이 가장 작은` — 승인 여부로 다투지 않게 한다
- `2023년 이후 세계에서 인구가 가장 많은 나라` — 2023년에 인도가 중국을 앞질렀다

실제로 걸렸던 사고:

- `가장 넓은 면적을 차지하는 기관` → 답을 피부로 뒀는데 보기에 소장이 있었다. 융모까지 세면 소장이 15배 넓다. → "가장 무거운 기관"으로 고침
- `임시정부가 처음 수립된 도시` → 답을 상하이로 뒀는데 보기에 블라디보스토크가 있었다. 시기로는 연해주가 먼저다. → "중국에서 수립된"으로 범위를 한정

## 3. 개선안 내기

⚠️·🔴로 판정한 문항마다 **고쳐 쓴 문장을 직접 제시할 것.** "기준을 명시하세요" 같은 지시로 끝내지 말 것 — 그건 개선안이 아니라 문제의 되풀이다.

고치는 방법은 넷이다. **위에 있는 것부터 시도할 것** — 아래로 갈수록 파급이 크다.

| 방법 | 언제 | 예 |
|---|---|---|
| ① 기준을 문제에 넣는다 | 어떤 잣대인지만 밝히면 답이 하나가 될 때 | `세계에서 가장 높은 산` → `**해발고도가** 세계에서 가장 높은 산` |
| ② 범위를 한정한다 | 잣대는 분명한데 대상 집합이 넓을 때 | `임시정부가 처음 수립된 도시` → `**3·1 운동 직후 중국에서 수립된** 임시정부가 처음 자리 잡은 도시` |
| ③ 시점을 박는다 | 값이 시간에 따라 변할 때 | `인구가 가장 많은 나라` → `**2023년 이후** 인구가 가장 많은 나라` |
| ④ 경쟁 보기를 교체한다 | ①~③으로도 그 보기가 답이 될 수 있을 때 | `가장 무거운 기관` 보기에서 **소장 → 뇌** |

정답 자체를 바꾸는 방향은 **마지막 수단**이다. 난이도 배치와 해설까지 함께 흔들린다.

해설도 함께 손볼 것. 좋은 해설은 **왜 다른 보기가 답이 아닌지**를 한 줄 담는다 — `그린란드는 약 216만㎢다. 호주는 더 넓지만 섬이 아니라 대륙으로 분류한다.`

## 4. 보고 형식

```
🔴 SC-012  사람의 몸에서 가장 넓은 면적을 차지하는 기관은?
   충돌   면적 기준이면 소장(융모 포함 약 30㎡)이 피부(약 2㎡)보다 넓다. 보기에 소장이 있다.
   개선   질문을 "가장 무거운 기관"으로 바꾸고(①), 보기의 소장을 뇌로 교체(④)
   해설   "피부는 약 4kg으로 가장 무겁다. 몸속 장기 중에서는 간이 약 1.5kg으로 가장 무겁다."
```

- 🔴 → ⚠️ 순으로, 심각한 것부터 낸다.
- ✅는 **개수만** 밝히고 나열하지 않는다.
- **오탐은 오탐이라고 밝힐 것.** `최고 권력 기구`·`최고 관직`·`최고 기구`는 역사 용어의 일부라 최상급이 아니고, `가장자리`는 단어에 '가장'이 들어갔을 뿐이다.
